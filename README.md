# SQA Mock Interview Skills

Custom skills for Software Quality Assurance and Automation engineers.

## Available Skills

### /SQAMockInterview
A comprehensive mock interview skill for SQAA engineers. Conducts realistic, scenario-based interviews with real-time feedback and scoring.

**Features:**
- Scenario-based questions across 8 domains (test automation, CI/CD, API testing, QA strategy, test data, performance testing, security testing, test leadership)
- Filtering by difficulty level (beginner, intermediate, advanced, expert)
- Company-aware context (startup, scale-up, enterprise, FAANG)
- Real-time feedback (1-5 scoring, strengths, gaps, best practices)
- Comprehensive interview summary with strengths, development areas, and interview readiness assessment

**Usage:**
```
/SQAMockInterview [topic] [difficulty] [company-level] [number-of-questions]
```

**Examples:**
```
/SQAMockInterview test automation advanced FAANG 6
/SQAMockInterview CI/CD intermediate startup 4
/SQAMockInterview API testing beginner any 3
/SQAMockInterview any expert mixed 5
```

## Installation

1. Download `SQAMockInterview.skill`
2. Open Claude Code
3. Click the plugin icon and select "Install skill"
4. Select the `.skill` file
5. Run `/SQAMockInterview` to start

## About

Created for SQAA engineers preparing for interviews or looking to strengthen their skills across multiple QA domains.

- **Topics Covered:** Test Automation, CI/CD, API Testing, QA Strategy, Test Data Management, Performance Testing, Security Testing, Test Leadership
- **Question Bank:** 21+ curated scenario-based questions
- **Scoring:** Detailed 1-5 rubric with industry best practices
- **Designed for:** All experience levels from beginners to experts
